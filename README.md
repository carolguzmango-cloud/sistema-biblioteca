# sistema-biblioteca

Este proyecto para la materia (Estructuras de Datos) implementa un sistema para la gestión de libros, usuarios y préstamos de una biblioteca. 
El sistema utiliza las siguientes estructuras de datos para cumplir con los requerimientos del curso:
-Listas: Para almacenar el catalogo general de los libros
-Pilas: Para el historial de ultimas acciones
-Colas: Para gestionar la cola de espera de préstamos de libros agotados
-Arboles binarios de búsqueda: Para realizar búsqueda eficientes de libros por ISBN o Título
